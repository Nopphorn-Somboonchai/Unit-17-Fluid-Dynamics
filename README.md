# ⚛️🌊 Interactive Physics Learning Portal
### รายวิชา ฟิสิกส์ 5 (ว33205) | ฟิสิกส์ ม.6 บทที่ 17.4 พลศาสตร์ของของไหล (Fluid Dynamics)

โปรเจกต์สื่อการสอนแบบโต้ตอบ (Interactive Web Application) ที่ถูกออกแบบมาเพื่อช่วยให้นักเรียนระดับชั้นมัธยมศึกษาปีที่ 6 เข้าใจกลศาสตร์การเคลื่อนที่ของของไหล (พลศาสตร์ของของไหล) ได้แก่ สมบัติของของไหลอุดมคติ (Ideal Fluid), อัตราการไหล ($Q = Av$), สมการความต่อเนื่อง ($A_1 v_1 = A_2 v_2$), สมการแบร์นูลลี ($P + \frac{1}{2}\rho v^2 + \rho g h = \text{const}$) ตลอดจนการประยุกต์ใช้งานในชีวิตประจำวัน (เช่น กฎของตอร์รีเชลลี, เครื่องพ่นละอองน้ำ, แรงยกปีกเครื่องบิน และปรากฏการณ์หลังคาบ้านปลิวในพายุ) ผ่านการจำลองภาพเสมือนจริง (Virtual Simulation) การฝึกทำโจทย์แบบสุ่ม และระบบสอบเก็บคะแนนแบบจับเวลา ตัวแอปพลิเคชันพัฒนาในรูปแบบ Single-File HTML เพื่อความสะดวกในการใช้งานแบบออฟไลน์หรือนำไปโฮสต์บนเว็บเซิร์ฟเวอร์ทั่วไปได้โดยไม่ต้องผ่านขั้นตอนการ Build

## ✨ ฟีเจอร์หลักของระบบ (Key Features)

### 1. 📖 ระบบทบทวนบทเรียนและเครื่องมือจำลอง (Interactive Review & Simulators)

* **Simulator 1: การไหลของของไหลอุดมคติและสมการความต่อเนื่อง (Ideal Fluid & Continuity Equation Simulator)**
  * จำลองการไหลของของไหลผ่านท่อที่มีการเปลี่ยนแปลงพื้นที่หน้าตัด ($A_1, A_2$) และวัดอัตราเร็ว ($v_1, v_2$)
  * แสดงการคำนวณอัตราการไหลคงตัว ($Q = A_1 v_1 = A_2 v_2$) และแสดงเส้นสายกระแส (Streamlines) แบบเรียลไทม์
* **Simulator 2: สมการแบร์นูลลีและการเปลี่ยนแปลงความดัน (Bernoulli's Principle Simulator)**
  * จำลองการไหลของของไหลในท่อที่มีระดับความสูงต่างกัน ($h_1, h_2$) และพื้นที่หน้าตัดต่างกัน
  * คำนวณและแสดงผลความดัน ($P$), พลังงานจลน์ต่อหนึ่งหน่วยปริมาตร ($\frac{1}{2}\rho v^2$) และพลังงานศักย์โน้มถ่วงต่อหนึ่งหน่วยปริมาตร ($\rho g h$) ณ จุดต่างๆ
* **Simulator 3: การประยุกต์ใช้พลศาสตร์ของของไหล (Fluid Dynamics Applications Simulator)**
  * จำลองปรากฏการณ์การประยุกต์ใช้สมการแบร์นูลลี เช่น อัตราเร็วของของไหลที่ออกจากรูด้านข้างภาชนะตามกฎของตอร์รีเชลลี ($v = \sqrt{2gh}$)
  * จำลองแรงยกปีกเครื่องบิน (Airplane Wing Lift) และหลักการทำงานของเครื่องพ่นละอองน้ำ

### 2. 🧠 ระบบตะลุยโจทย์เฉพาะตัว (Roll-Number-Based Practice System)
* **โหมดการเรียนรู้**: เลือกได้ระหว่างโจทย์ตัวเลขคงที่ (อิงตามคู่มือเรียน สสวท.) และโจทย์สุ่มตัวเลข (RNG)
* **หัวข้อคลังข้อสอบย่อย**:
  * **17.4.1 ของไหลอุดมคติและอัตราการไหล**: สมบัติ 4 ประการของของไหลอุดมคติ และคำนวณอัตราการไหล $Q = \frac{\Delta V}{\Delta t} = A v$
  * **17.4.2 สมการความต่อเนื่อง**: คำนวณหาอัตราเร็วหรือพื้นที่หน้าตัดท่อเมื่อของไหลไหลผ่าน $A_1 v_1 = A_2 v_2$
  * **17.4.3 สมการแบร์นูลลีและการประยุกต์**: คำนวณความดัน อัตราเร็ว และความสูงตามสมการแบร์นูลลี $P_1 + \frac{1}{2}\rho v_1^2 + \rho g y_1 = P_2 + \frac{1}{2}\rho v_2^2 + \rho g y_2$ รวมถึงการประยุกต์ใช้กฎของตอร์รีเชลลี ($v = \sqrt{2gh}$) และแรงยกปีกเครื่องบิน
* **ระบบเฉลยละเอียด**: แสดงผลการตรวจคำตอบทันทีพร้อมวิธีทำคำนวณสูตรฟิสิกส์ทีละขั้นตอนอย่างละเอียดในรูปแบบอักษรคณิตศาสตร์ที่สวยงาม

### 3. ⏱️ ระบบสอบเก็บคะแนน (Timed Exam System)

* **ระบบจำลองการสอบแบบจำกัดเวลา**: จำนวน 5 ข้อ (คะแนนเต็ม 10 คะแนน) โดยมีระยะเวลาจำกัดในการทำข้อสอบ **15 นาที** พร้อมตัวจับเวลาถอยหลัง (*Timer*) ในแถบเมนูด้านบน
* **การสอบแบบผสมผสาน**: ระบบจะสุ่มข้อสอบโดยมี **ข้อสอบแบบเลือกตอบ (Choice) เพียง 1 ข้อ** และ **ข้อสอบแบบคำนวณตัวเลข (Numeric Input) อีก 4 ข้อ** เพื่อวัดผลทั้งความเข้าใจเชิงทฤษฎีและทักษะการคำนวณเกี่ยวกับพลศาสตร์ของของไหลอย่างรอบด้าน
* **ระบบป้องกันการโกง (Anti-cheat guard)**: แจ้งเตือนและป้องกันการรีเฟรชหน้าจอหรือออกจากหน้าสอบโดยไม่ตั้งใจ
* **Dashboard สรุปผล**: แสดงคะแนนรวม เวลาที่ใช้ พร้อมตารางสรุปสถานะการตอบแต่ละข้อ และปุ่มดูเฉลยละเอียดวิธีคิดอย่างเป็นขั้นเป็นตอน
* **ระบบบันทึกผลคะแนน**: บันทึกผลสอบล่าสุดเก็บไว้ใน `LocalStorage` ของเบราว์เซอร์ เพื่อให้ผู้เรียนสามารถตรวจสอบคะแนนล่าสุดได้ที่หน้าแรก
</details>

## 🎯 กฎระบบข้อสอบแปรผัน (Dynamic Quiz System Rules)

<details>
<summary><b>⚙️ คลิกเพื่อแสดงกฎเกณฑ์และสถาปัตยกรรมเบื้องหลัง</b></summary>

ระบบข้อสอบในโปรเจกต์นี้ได้รับการออกแบบให้เป็น **Non-Deterministic Dynamic System** โดยผูกค่าตัวแปรในโจทย์เข้ากับ **"เลขที่ของนักเรียน (Roll Number: $R$)"** เพื่อให้มั่นใจว่านักเรียนแต่ละคนจะได้รับพารามิเตอร์โจทย์และคำตอบสุดท้ายที่ไม่ซ้ำกัน

### 📌 สถาปัตยกรรมและลอจิกการทำงาน:
1. **Dynamic Parameter Generation**: ระบบจะดึงเลขที่ของนักเรียน ($R$ ตั้งแต่ 1-40) มาคำนวณร่วมกับฐานตัวแปรที่ถูกสุ่มขึ้นมาแบบอิสระ (*Non-deterministic Random*) เช่น `P = P_base + R` หรือการบวกค่าเลขที่เข้าไปในปริมาตรความลึก เพื่อสร้างค่าพารามิเตอร์ชุดใหม่สำหรับโจทย์แต่ละข้อ
2. **On-the-fly Validation**: การประเมินคำตอบและเฉลยวิธีทำจะคำนวณแบบสด ๆ (*On-the-fly*) จากเลขที่ $R$ ของผู้เข้าสอบจริง โดยไม่ใช้ค่าคงที่ตายตัว (*No Static Hardcoded*)
3. **Safety Constraints**: สมการเบื้องหลังได้รับการกำหนดขอบเขตค่าต่ำสุด-สูงสุดไว้อย่างรัดกุม เพื่อป้องกันไม่ให้การคำนวณร่วมกับเลขที่ $R$ เกิดค่าที่ติดลบหรือไม่สมเหตุสมผลทางฟิสิกส์
</details>

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

<details>
<summary><b>💻 คลิกเพื่อแสดงรายชื่อเทคโนโลยีที่นำมาประยุกต์ใช้</b></summary>

* **HTML5**: สำหรับจัดวางโครงสร้างและเนื้อหาเว็บแอปพลิเคชัน
* **Vanilla CSS (`style.css`)**: สำหรับการตกแต่งเพิ่มเติม เช่น แอนิเมชันกระบอกสูบ ปรับแต่ง Scrollbar และเอฟเฟกต์การตอบสนองของปุ่มต่าง ๆ
* **JavaScript (ES6+ / `app.js`)**: สำหรับควบคุมลอจิกทั้งหมด ระบบคำนวณฟิสิกส์ อัลกอริทึมการสุ่มและตรวจข้อสอบ ตลอดจนตัวจับเวลาและการพ่นกราฟบน HTML5 Canvas
* **Tailwind CSS (via CDN)**: ใช้ในการจัดการ UI/UX, สีสัน, รูปแบบ Grid/Flex Layout และความ Responsive รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน
* **KaTeX (via CDN)**: ไลบรารีประสิทธิภาพสูงสำหรับเรนเดอร์สมการคณิตศาสตร์และสูตรฟิสิกส์ด้วยฟอร์แมต $\text{\LaTeX}$
* **Lucide Icons**: บริการไอคอนเวกเตอร์ที่ทันสมัยสำหรับใช้แสดงสัญลักษณ์ในหน้าเว็บ
* **Google Fonts**: นำเข้าฟอนต์ 'Prompt' และ 'Sarabun' เพื่อให้อ่านง่าย สบายตา และดูมีความเป็นสากลและวิชาการ
</details>

## 🚀 วิธีการใช้งาน (How to Run)

<details open>
